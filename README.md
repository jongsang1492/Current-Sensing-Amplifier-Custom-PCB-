# Current Sensing Amplifier – Custom PCB Design

This project implements a **current sensing signal conditioning circuit and custom PCB** designed to measure load current in a programmable power supply system.

The circuit converts the small voltage drop across a **0.1 Ω current sense resistor** into a scaled analog voltage that can be accurately measured by a microcontroller ADC.

The design includes **signal amplification, offset shifting, and noise filtering**, enabling reliable current measurement across the operating range.

---

# System Overview

The current sensing module monitors load current and outputs a proportional voltage signal suitable for microcontroller ADC input.

# Design Specifications

The circuit was designed according to the following electrical requirements.

| Parameter | Value |
|---|---|
| Load current range | 0 – 3.5 A |
| Sense resistor | 0.1 Ω |
| Input sense voltage | 0 – 0.35 V |
| Output voltage range | 0.25 – 3.3 V |
| Amplifier supply | +19 V |
| Op-amp used | LM324 |

The output voltage is linearly proportional to the load current.

Example operating points:

| Load Current | Sense Voltage | Output Voltage |
|---|---|---|
| 0 A | 0 V | 0.25 V |
| 1 A | 0.1 V | 1.12 V |
| 3.5 A | 0.35 V | 3.3 V |

---

# Circuit Design

The analog signal conditioning circuit is built using **LM324 operational amplifiers**.

The amplifier stages perform three main functions:

- **Signal amplification** to scale the small sense voltage
- **Voltage offset shifting** to ensure the output stays within ADC range
- **Signal conditioning** to stabilize the output voltage

<img width="1295" height="488" alt="Circuit Schematic" src="https://github.com/user-attachments/assets/077f06a9-bf88-4268-88dc-9d3b701d0099" />

The resulting output voltage provides a stable and linearly scaled representation of the measured load current.

---

# Low-Pass Filter Design

A low-pass filter stage was added to suppress high-frequency noise generated by the switching power supply.

Design targets:

- Passband: ≤ 1 kHz
- Stopband attenuation: ≥ 35 dB at 5 kHz
- Minimal attenuation within the passband

This filtering stage prevents high-frequency switching noise from affecting ADC measurements and improves overall signal stability.
