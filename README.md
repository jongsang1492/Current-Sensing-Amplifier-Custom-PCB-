# Current-Sensing-Amplifier-Custom-PCB-
Designed an LM324-based signal conditioning circuit converting 0–0.35 V sensor output to 0.25–3.3 V microcontroller input range
# Current Sense Amplifier PCB

This project implements a **current sensing circuit and custom PCB** designed to measure load current in a programmable power supply system.

The circuit converts the voltage drop across a **0.1 Ω current sense resistor** into a scaled analog voltage that can be read by a microcontroller ADC.

The system was designed and fabricated as part of an analog electronics design project.

---

# System Overview

The current sensing module measures load current and outputs a proportional voltage signal for digital monitoring.

• Microcontroller ADC interface

# Design Specifications

The circuit was designed according to the following requirements:

| Parameter | Value |
|---|---|
| Load current range | 0 – 3.5 A |
| Sense resistor | 0.1 Ω |
| Input sense voltage | 0 – 0.35 V |
| Output voltage range | 0.25 – 3.3 V |
| Amplifier supply | +19 V |
| Op-amp used | LM324 |

The output voltage is linearly proportional to the load current.

Example operating points:

| Load Current | Sense Voltage | Output Voltage |
|---|---|---|
| 0 A | 0 V | 0.25 V |
| 1 A | 0.1 V | 1.12 V |
| 3.5 A | 0.35 V | 3.3 V |

# Circuit Design

The analog circuit uses **LM324 operational amplifiers** to perform:

• Signal amplification  
• Voltage offset shifting  
• Noise filtering  

The amplified signal is then suitable for microcontroller ADC measurement.

# Low-Pass Filter Design

A low-pass filter stage was added to remove high-frequency noise generated by the switching power supply and prevent aliasing during ADC sampling.

Design targets:

• Passband: ≤ 1 kHz  
• Stopband attenuation: ≥ 35 dB at 5 kHz  
• Minimal attenuation in the passband  

This ensures accurate current measurement while suppressing switching noise.
